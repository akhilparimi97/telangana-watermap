# Telangana WaterMap Collaboration Board

This file is intentionally editable. Use it to coordinate waterbody, intake, and outflow research before changing the map data.

## Working rules

- Prefer authoritative Telangana government, ICAD, TGRAC, CWC, India-WRIS, and published project documents.
- Use OpenStreetMap as supplemental evidence, not as the sole authority for irrigation infrastructure.
- Keep observed, official, and inferred geometry distinct.
- Do not call an inferred lift corridor a surveyed pipeline.
- Record disagreements instead of silently choosing one source.

## Priority work queue

### Waterbody location and identity

- [ ] Verify reservoir and tank coordinates against source geometry.
- [ ] Resolve duplicate names and aliases.
- [ ] Record missing district, basin, project, and source IDs.
- [ ] Identify candidate waterbodies that need official confirmation.

### Lift intakes

- [ ] Match each lift project to the nearest plausible barrage, weir, regulator, or river intake.
- [ ] Record whether the intake is official, mapped structure evidence, or inferred from proximity.
- [ ] Add intake coordinates and supporting evidence.
- [ ] Flag projects where multiple intake candidates remain plausible.

### Outflow and destination points

- [ ] Identify receiving reservoirs, canals, command areas, balancing reservoirs, or distribution nodes.
- [ ] Record destination coordinates and the evidence for the connection.
- [ ] Distinguish project destination from actual outlet or discharge point.
- [ ] Flag routes that require field or document verification.

### Flow and terrain review

- [ ] Check river and stream direction against terrain and authoritative hydrography.
- [ ] Review canal continuity and disconnected segments.
- [ ] Identify crossings, regulators, tunnels, and pumping stages.
- [ ] Separate measured discharge from DEM-derived interpretation.
